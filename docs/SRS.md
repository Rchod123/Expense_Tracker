# AI Smart Expense Tracker
Description
A cross-platform mobile application that enables users to record income and expenses, analyse spending habits and receive AI-powered financial insights while supporting offline usage.

# 2. Problem  statement
Many expense tracking applications require users to manually categorise transactions and provide only static reports.
Users often struggle to understand:
Where money is going
Which categories are increasing
How much they can realistically save
Spending trends over time
Our application addresses these issues by combining traditional expense tracking with AI-generated categorisation and personalised insights.

# 3. Objectives
The application should enable users to:
> Track income
> Track expenses
Categorise expenses
Search transactions
Generate reports
Export reports
Work offline
Receive AI-generated spending insights
